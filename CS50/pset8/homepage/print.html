Essa é a página explicando o uso do print em Python

O print é uma função em python que é utilizado para retornar uma string ao terminal de uso, levando consigo entre parênteses uma string como argumento obrigatório, e outros argumentos opicionais, sendo eles:

    sep = '', em que é definido entre aspas o caractere que separa 2 valores, naturalmente um caractere nulo (inserido apenas caso tenha mais de 2 valores como argumento) end = '', em que é definido o caractere ao final da string. Diferente de "sep", é um caractere inserido naturalmente para indicar o final de uma linha, para o terminal pular para a próxima. file =(nome do arquivo). Naturalmente o print mostra os valores no console, mas com esse comando, ele escreve os mesmos valores, porém em um arquivo flush = (bool). Esse comando faz com que o python não espere o buffer para mostrar os valores. Para ter um exemplo melhor, execute o código abaixo sem o argumento "flush":
import time
 
for _ in range(5):

    print('.', end='', flush = True)

    time.sleep(0.5)

print(' Pronto!')
